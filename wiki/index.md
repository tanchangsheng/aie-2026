| [MCP Gateway](concepts/mcp-gateway.md) | Centralized MCP proxy; four caller patterns ranked by context cost |

| [Agent Skills](concepts/agent-skills.md) | Portable, eval-gated units of expertise shared across agent harnesses |
| [Context Graph](concepts/context-graph.md) | Org-wide knowledge graph cutting tool-call fan-out for cross-system questions |
| [AI Code Review](concepts/ai-code-review.md) | Inner/outer loop split, generator-verifier grading, and confidence-scored suppression for AI code review at scale |
| [Model Routing](concepts/model-routing.md) | Dynamic per-request model selection; routing vs. gateway distinction; six approaches from heuristic to RL; KV-cache-aware agent-native routing; Factory Router as second production example |
| [Guardrails](concepts/guardrails.md) | Safety/policy checks on LLM inputs and outputs; fail-open vs. fail-closed by blast radius; time budgets; parallel placement as the preferred default |
| [Software Factory](concepts/software-factory.md) | The full autonomous dev cycle (spec → build → validate → deploy → learn); three required properties: agnostic, autonomous, always-improving |
| [Agent Readiness](concepts/agent-readiness.md) | Measurable degree to which a codebase supports autonomous agent work; scoring rubric (Factory) and infrastructure approach (Uber) |
| [Agent Environment Architecture](concepts/agent-environment-architecture.md) | Control Plane / Data Plane split; devbox trust model; how Ramp, Uber, and OpenRouter each implement fast-booting, secrets-isolated agent workspaces; microVM anatomy and primitive-to-control mapping (Orellana) |
| [Silent Semantic Failure](concepts/silent-semantic-failure.md) | When a tool call returns success but the bytes are wrong — Byzantine fault, agent overtrust, and why completion-based monitoring can't catch it |
| [Agent-Driven Testing](concepts/agent-driven-testing.md) | LLM agent authors and runs its own test suite against the service it will use — the methodology Orellana used to find 18 failure modes in AgentCore |
| [Harness Engineering](concepts/harness-engineering.md) | The scaffolding that turns a model into an agent: context, control, observe, action, persist, hooks, ratchet |
| [Loop Engineering](concepts/loop-engineering.md) | Designing the system that prompts agents — not just the prompts. Design the loop, not the prompt. |
| [Human Verdict](concepts/human-verdict.md) | The accountable human decision at the boundary between agent-generated evidence and production; the node where "lights off fails"; now 2 sources (Osmani + Resolve AI) |
| [Taste as Alpha](concepts/taste-as-alpha.md) | Taste — judgment before the metric exists — as the primary decay-resistant human differentiator; alpha vs. decay framework |
| [Cognitive Debt](concepts/cognitive-debt.md) | Three failure modes from AI over-reliance: cognitive debt (loss of understanding), cognitive surrender (blindly accepting AI output), orchestration tax (managing too many agents) |
| [Inference Control Plane](concepts/inference-control-plane.md) | A unified system managing routing, scheduling, autoscaling, cost, observability, policy, reliability, admission control, and multi-tenancy for an inference fleet; "models become resources" |
