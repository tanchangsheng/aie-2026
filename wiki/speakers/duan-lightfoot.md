## Recurring Themes

- Self-hosted inference as the operationally honest alternative to rented APIs — cost, data residency, rate-limit control
- Making the inference layer legible: metrics, memory budgets, request traces rather than black-box endpoints
- Agents as clients of the inference layer, not as the layer itself — the framework doesn't matter if the model is slow
- Kubernetes-native deployment without cluster admin: namespaced Deployments, scoped kubeconfigs, short Service names
